# מנעול חכם (SmartLock)

נעילת אפליקציות לאנדרואיד: קוד PIN (6 ספרות, מקלדת מעורבבת), טביעת אצבע / זיהוי פנים של המכשיר,
הגנה מפני ניחושים (נעילה מתגברת), צילום פולש.

## בניית APK
**אפשרות 1 – GitHub (בלי להתקין כלום):** העלה את התיקייה כולה לריפו חדש ב-GitHub → לשונית Actions →
"Build APK" → בסיום הורד את `SmartLock-APK` (בתוכו app-debug.apk).

**אפשרות 2 – Android Studio:** File → Open על התיקייה, המתן ל-Sync, ואז Build → Build APK(s).
הקובץ: app/build/outputs/apk/debug/app-debug.apk

## התקנה והפעלה
1. התקן את ה-APK, פתח את האפליקציה והגדר קוד PIN.
2. לחץ "הפעל שירות נעילת אפליקציות" ← הפעל את "מנעול חכם" בהגדרות הנגישות.
   באנדרואיד 13+: אם האפשרות אפורה → הגדרות ← אפליקציות ← מנעול חכם ← ⋮ ← "אפשר הגדרות מוגבלות".
3. סמן אילו אפליקציות לנעול.
